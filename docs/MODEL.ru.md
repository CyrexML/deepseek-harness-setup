# Модель: что скачать, куда положить и как настроить

**[English version](MODEL.md)**

Коротко: **ничего выбирать руками не нужно**. Запустите мастер

```powershell
powershell -ExecutionPolicy Bypass -File windows\20-model.ps1
```

он посмотрит на вашу видеокарту, предложит подходящую модель, скачает её в нужную
папку и сам пропишет настройки. Ниже — то же самое словами, если хочется сделать
руками или понять, что происходит.

---

## 1. Куда класть файлы

Всё лежит в одной папке — той, что указана в `config.json` как `windowsRoot`:

```
F:\Harness_AI\
  models\
    <модель>.gguf          ← сама модель (главный файл, 8–30 ГБ)
    mmproj-F16.gguf        ← «глаза» модели: распознавание картинок (необязательно)
    chat-agent.jinja       ← шаблон диалога (кладёт установщик, править не нужно)
  llama.cpp\               ← движок, ставит установщик
  run\                     ← логи и скрипты запуска
```

Папку `models` создаёт установщик. Файл модели просто кладётся туда — ничего
распаковывать и переименовывать не нужно. Диск может быть любым (C:, D:, F:) —
важно только, чтобы путь совпадал с `windowsRoot` в `config.json`.

## 2. Какую модель брать

Решает объём видеопамяти (VRAM), а не мощность карты. Посмотреть свой объём:

```powershell
nvidia-smi --query-gpu=name,memory.total --format=csv
```

| Видеопамять | Модель | Файл | Окно контекста |
|---|---|---|---|
| 10 ГБ | Qwen3.5 9B (MTP) | `Qwen3.5-9B-MTP-UD-Q4_K_XL.gguf` (6.1 ГБ) | 32k |
| 12 ГБ | Qwen3.5 9B (MTP) | `Qwen3.5-9B-MTP-UD-Q5_K_XL.gguf` (6.9 ГБ) | 48k |
| 14 ГБ | Qwen3.5 9B (MTP) | `Qwen3.5-9B-MTP-UD-Q6_K_XL.gguf` (9.0 ГБ) | 64k |
| 16 ГБ | Qwen3.8 27B | `Qwen3.8-27B-UD-Q3_K_XL.gguf` (13 ГБ) | 64k ← под это настроено |
| 24 ГБ | Qwen3.8 27B | `Qwen3.8-27B-UD-Q4_K_XL.gguf` (17 ГБ) | 64k |
| 32 ГБ+ | Qwen3.8 27B | `Qwen3.8-27B-Q5_K_M.gguf` (21 ГБ) | 128k |

Обе линейки умеют предсказывать несколько токенов вперёд (MTP) — на этом держится
скорость генерации стенда, поэтому в каталоге только такие сборки.

Правило простое: **файл модели должен занимать примерно 80% вашей VRAM**.
Остальное уходит на контекст (историю диалога) и служебные буферы. Если модель
не влезает — она частично поедет на процессор, и скорость упадёт в 5–20 раз.

Кванты (`Q3`, `Q4`, `Q5`) — это степень сжатия весов. Чем меньше число, тем
меньше файл и тем хуже качество ответов. `UD-` у Unsloth означает «динамический»
квант: важные слои сжаты слабее, поэтому UD-Q3 заметно лучше обычного Q3.

## 3. Как скачать

**Способ 1 — мастером (рекомендуется).** `windows\20-model.ps1` скачает выбранный
файл с проверкой контрольной суммы и возобновлением после обрыва.

**Способ 2 — руками.** Открыть страницу модели на Hugging Face, скачать нужный
`.gguf` и положить в `F:\Harness_AI\models\`:

- Qwen3.8 27B: <https://huggingface.co/unsloth/Qwen3.8-27B-GGUF>
- Qwen3.5 9B (MTP): <https://huggingface.co/unsloth/Qwen3.5-9B-MTP-GGUF>

В списке файлов репозитория берите ровно тот, чьё имя указано в таблице выше.
Файлы вида `...-00001-of-00002.gguf` — это модель, разрезанная на части: нужно
скачать ВСЕ части в одну папку, движок склеит их сам.

**Способ 3 — консолью** (быстрее и с докачкой):

```powershell
pip install -U "huggingface_hub[cli]"
hf download unsloth/Qwen3.8-27B-GGUF Qwen3.8-27B-UD-Q3_K_XL.gguf --local-dir F:\Harness_AI\models
```

Распознавание картинок (необязательно): из того же репозитория файл `mmproj-F16.gguf`.
Без него стенд работает, просто не видит вложенные изображения.

## 4. Настройка после скачивания

Это то место, где раньше приходилось всё подбирать вручную. Теперь:

```powershell
powershell -ExecutionPolicy Bypass -File windows\30-tune.ps1
```

Мастер сам:

1. читает объём VRAM и размер файла модели;
2. считает, какое окно контекста влезает (`ctx`) при сжатом KV-кэше `q4_0`;
3. включает спекулятивное декодирование (MTP), если модель его поддерживает;
4. записывает всё в `config.json` и в команду запуска `run\start-server.ps1`;
5. поднимает сервер и делает контрольный замер: печатает скорость префилла и
   генерации в токенах в секунду;
6. создаёт пресет DSH (`local-<ctx>`), чтобы интерфейс знал размер окна и модель.

Ничего править руками после этого не нужно. Если хочется — все значения лежат в
`config.json` в разделе `server`, а мастер можно перезапустить.

### Что именно настраивается и зачем

| Параметр | Что это | Почему так |
|---|---|---|
| `-ngl 99` | сколько слоёв модели уходит на видеокарту | все: иначе скорость падает в разы |
| `--fit off` | не «ужимать» модель автоматически | подбор делаем мы, а не движок |
| `-c <ctx>` | размер окна контекста в токенах | больше окно — больше VRAM под кэш |
| `--cache-type-k/v q4_0` | сжатие кэша диалога | ровно вдвое больше окно при той же VRAM; `q4_0` выбран потому, что с ним работает быстрое ядро FlashAttention |
| `--spec-type draft-mtp` | предсказание нескольких токенов вперёд | +30–60% к скорости генерации на моделях с MTP |
| `--reasoning-budget 5000` | потолок «размышлений» на шаг | без потолка модель может думать бесконечно |
| `--chat-template-file` | свой шаблон диалога | вырезает повтор размышлений из истории: без этого контекст растёт в разы быстрее |

## 5. Проверка, что всё хорошо

```powershell
powershell -ExecutionPolicy Bypass -File windows\30-tune.ps1 -CheckOnly
```

Печатает: модель, окно, занятую видеопамять, скорость префилла и генерации.
Ориентиры на RTX 5080 (27B UD-Q3_K_XL, окно 64k):
префилл ~1970 ток/с, генерация ~95 ток/с, свободной VRAM 150–500 МиБ.

Если генерация заметно ниже 20 ток/с — модель почти наверняка не влезла в VRAM:
возьмите квант поменьше или уменьшите `ctx`.

## 6. Частые вопросы

**«Можно другую модель, не Qwen?»** Да, любой GGUF, который понимает llama.cpp.
Но шаблон диалога (`chat-agent.jinja`) написан под Qwen3; для другой модели
уберите строку `chatTemplateFile` из `config.json` — будет использован шаблон,
зашитый в сам файл модели. Спекулятивное декодирование (MTP) есть не у всех
моделей: мастер проверит и выключит его, если его нет.

**«Модель скачана в другую папку, копировать?»** Не нужно: укажите путь в
`config.json` → `model.path`, мастер примет любой путь.

**«Сколько это занимает места?»** Модель 13 ГБ + движок ~2 ГБ + харнес ~3 ГБ.
С запасом — 40 ГБ.

**«Интернет нужен постоянно?»** Нет. Он нужен один раз, при установке. Дальше
стенд работает полностью локально; интернет нужен только для доступа с телефона
через туннель.
