# Доступ с телефона

**[English version](MOBILE.md)**

Стенд работает в браузере телефона как обычное приложение: переписка, файлы
проекта, просмотр результата. Есть два способа дотянуться до компьютера.

## Способ 1: домашняя сеть (проще, работает сразу)

Если телефон и компьютер в одной сети Wi-Fi, ничего настраивать не нужно:
узнайте адрес компьютера и откройте его на телефоне.

```powershell
ipconfig | findstr IPv4
```

Адрес вида `http://192.168.1.50:3080`. Интерфейс просит токен — он печатается
при запуске стенда и лежит в `run/web.log`.

Минусы: только дома и только пока оба устройства в одной сети.

## Способ 2: Cloudflare Tunnel (из любой точки)

Туннель даёт постоянный адрес вида `https://ваш-домен`, работающий откуда
угодно, без проброса портов и «белого» IP.

1. Заведите бесплатный аккаунт Cloudflare и добавьте домен (подойдёт любой,
   в том числе дешёвый).
2. В `config.json` включите туннель:
   ```json
   "tunnel": { "enabled": true, "domain": "dsh.ваш-домен" }
   ```
3. Запустите шаг настройки:
   ```powershell
   powershell -ExecutionPolicy Bypass -File install.ps1 -Step wsl
   ```
   Плагин моста проведёт вход в Cloudflare и выпустит туннель.

### Если телефон получает 530

Такое бывает, и почти всегда причина одна из двух:

**Провайдер режет порт 7844.** Cloudflare Tunnel держит соединение через TCP
7844, и некоторые сети (особенно мобильные и гостиничные) его блокируют.
Проверка с компьютера:

```powershell
Test-NetConnection 198.41.192.167 -Port 7844
```

Если порт закрыт — туннель не поднимется, пока вы не включите VPN или не
смените сеть. Обычный HTTPS при этом работает, поэтому диагностика без этой
проверки заводит в тупик.

**Cloudflared сдался после обрыва.** По умолчанию он выходит после пяти
неудачных попыток. В наших скриптах запуска это уже исправлено
(`TUNNEL_RETRIES=1000`), но если туннель поднимали руками — проверьте
`run/cloudflared.log`.

## Что сделано специально для телефона

Интерфейс харнеса рассчитан на монитор, поэтому мост дорабатывается нашими
патч-слоями:

- шторка с сессиями, кнопка питания, экран загрузки, поворот экрана по системной
  блокировке, иконка для «на домашний экран»;
- **окно вопросов модели** не перекрывает переписку: занимает не больше 45%
  экрана, сворачивается в полоску одним касанием и не закрывается случайно —
  закрытие спрашивает подтверждение, потому что для модели это отмена вопроса;
- **щипок** не масштабирует переписку (мешало при наборе), но масштабирует
  содержимое просмотра — страницу, PDF, таблицу; сама панель при этом стоит на
  месте. Двойное касание двумя пальцами возвращает 100%;
- нет синей вспышки при нажатии — вместо неё короткое затемнение;
- PDF и офисные документы открываются прямо в панели, без скачивания;
- ссылка на файл из переписки открывает его в панели так же, как из проводника.

## Установка как приложения

В браузере телефона: меню → «Добавить на главный экран». Дальше стенд
открывается как обычное приложение, без адресной строки.
